MarkdownNote は、Markdown に特化したシンプルで使いやすいメモアプリです。ちょっとしたアイデアのメモから、見出しや表を使ったまとまった文書まで、幅広い用途に対応しています。

■ 本格的な Markdown エディタ
CommonMark 準拠の Markdown 記法に完全対応。GitHub Flavored Markdown の拡張機能（テーブル・取り消し線）もサポート。初めての方にも安心なプレースホルダーのヒント付きです。

■ 3 つの編集モード
用途に合わせてモードを切り替えられます。
・編集モード — 書くことだけに集中
・分割モード — Markdown ソースとレンダリング結果をリアルタイムで並べて表示
・閲覧モード — 整形済みのドキュメントとして快適に読む

■ 瞬時に絞り込める検索
入力するたびにリアルタイムでメモを絞り込み。目的のメモにすぐアクセスできます。

■ スワイプで削除
左にスワイプするだけで削除操作を開始。誤削除を防ぐ確認ダイアログ付きです。

■ ファイル出力
メモを 3 つの形式でエクスポートできます。
・プレーンテキスト（.txt）
・Markdown（.md）
・HTML（.html）
ファイルはデバイスのドキュメントフォルダに保存され、他のアプリですぐに開けます。

■ 完全オフライン・プライバシー重視
すべてのメモはデバイス内の SQLite データベースにローカル保存。アカウント不要、インターネット接続不要、データが外部に送られることは一切ありません。

■ Material Design 3 対応
最新の Material You デザインシステムを採用。モダンで洗練されたデザインが、あらゆる Android デバイスに自然になじみます。
